# مصروفي 💳

تطبيق آيفون يسجّل مصاريفك **تلقائياً كل ما تدفع بـ Apple Pay**: المبلغ، المتجر، البطاقة، والمكان على الخريطة. وتقدر تضيف صورة الفاتورة وملاحظة لأي عملية.

## المميزات
- تسجيل تلقائي مع كل دفعة Apple Pay (عن طريق أتمتة «المعاملة» في تطبيق الاختصارات)
- مكان الدفع على الخريطة
- تصوير الفاتورة أو اختيارها من الصور
- تصنيف تلقائي (مطاعم، قهوة، بنزين، بقالة…) وتقدر تغيّره
- إحصائيات شهرية: حسب التصنيف، الصرف اليومي، أكثر المتاجر، ومقارنة بالشهر اللي قبله
- إضافة عملية يدوياً (للكاش مثلاً)
- تصدير كل العمليات لملف CSV يفتح في Excel أو Numbers
- كل البيانات محفوظة على جوالك بس

## المتطلبات
- ماك عليه **Xcode 16 أو أحدث** (مجاني من App Store)
- آيفون عليه **iOS 17 أو أحدث**
- حساب Apple ID (المجاني يكفي)

## التثبيت على جوالك
1. نزّل المشروع على الماك:
   ```bash
   git clone https://github.com/alhanaee-create/Payment.git
   ```
2. افتح الملف `Masrofi.xcodeproj` (دبل كليك).
3. في Xcode: اضغط على **Masrofi** في القائمة اليسار ← تبويب **Signing & Capabilities** ← في **Team** اختر حسابك (لو ما يطلع، اضغط Add Account وسجّل بـ Apple ID حقك).
   - لو طلع خطأ في Bundle Identifier، غيّره لأي شي فريد مثل `com.yourname.masrofi`.
4. وصّل الآيفون بالماك بالكيبل، واختره من فوق (بدل المحاكي).
5. اضغط زر التشغيل ▶️.
6. أول مرة، الآيفون بيطلب:
   - **وضع المطوّر**: الإعدادات ← الخصوصية والأمان ← وضع المطوّر ← فعّله (الجوال يعيد التشغيل).
   - **الوثوق بالمطوّر**: الإعدادات ← عام ← إدارة الأجهزة والـVPN ← اختر حسابك ← وثوق.
7. شغّل التطبيق ووافق على الموقع والإشعارات.

> ⚠️ مع حساب Apple ID المجاني، التطبيق يشتغل **7 أيام** وبعدها لازم تعيد الخطوة 5 من Xcode (بياناتك ما تنحذف). مع حساب مطوّر مدفوع (99$ بالسنة) يشتغل سنة كاملة.

## ضبط التسجيل التلقائي مع Apple Pay (مرة وحدة)
نفس الخطوات موجودة داخل التطبيق في تبويب **الإعداد**:

1. افتح تطبيق **الاختصارات** ← **الأتمتة** ← **+**
2. اختر **المعاملة** (Transaction)
3. حدّد بطاقاتك، واختر **تشغيل فوراً**، ثم **التالي**
4. **أتمتة فارغة جديدة** ← أضف إجراء **الحصول على الموقع الحالي**
5. أضف إجراء **سجّل مصروف** من **مصروفي**
6. اربط الخانات:
   - المبلغ ← مدخلات الاختصار ← **المبلغ**
   - المتجر ← مدخلات الاختصار ← **التاجر**
   - البطاقة ← مدخلات الاختصار ← **البطاقة**
   - الموقع ← **الموقع الحالي**
7. **تم** ✅

## ليش عن طريق الاختصارات؟
أبل ما تسمح لأي تطبيق يقرأ عمليات Apple Pay مباشرة. الطريقة الرسمية الوحيدة هي أتمتة «المعاملة» في الاختصارات، وهي اللي تعطي المبلغ واسم التاجر وقت الدفع، وترسلها لـ«مصروفي».
